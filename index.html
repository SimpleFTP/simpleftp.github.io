SimpleFTP

A powerful yet straightforward FTP/SFTP client for macOS. Built on RFC 959 standards, it prioritizes simplicity and reliability for seamless file transfers.

Unlimited Connections

Connect to multiple servers simultaneously without limits. Handle complex workflows efficiently.

Resumable Transfers

Uploads and downloads resume automatically if interrupted, provided the server supports it. No lost progress.

Drag & Drop Simplicity

Transfer files and folders effortlessly—just drag and drop. Intuitive for daily use.

Smart Synchronization

Sync directories with upload-only, download-only, or bidirectional modes. Handles conflicts intelligently.

Bookmarks & Broad Compatibility

Quick access to favorite servers. Supports FTP, FTP over TLS, SFTP across UNIX, Windows, OS/2, and macOS servers.

How It Works

Step 1: Connect

Add a server via URL, credentials, or bookmark. Supports unlimited simultaneous connections.

Step 2: Browse & Select

Navigate remote directories. Select files, folders, or use multi-select for batches.

Step 3: Transfer

Drag and drop locally or remotely. Resumes automatically; sync with smart modes.

Step 4: Manage

Delete, bookmark, or synchronize. Version 4.6.2 fixes sync conflict resolution for flawless operation.
